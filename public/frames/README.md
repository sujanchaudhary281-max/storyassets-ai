# Device Frames

Place device frame PNG files here for screenshot compositing.

## Required Files

- `iphone-15-pro-frame.png` — 1242×2688 iPhone 15 Pro frame with transparent screen area
- `pixel-8-pro-frame.png` — 1080×1920 Pixel 8 Pro frame with transparent screen area

## Where to Get Them

1. **Official Apple Design Resources**: https://developer.apple.com/design/resources/
2. **Official Android Design Resources**: https://developer.android.com/design
3. **Facebook Design (free device mockups)**: https://design.facebook.com/toolsandresources/devices/

## Notes

Until real frames are added, the worker uses a simple rounded-rectangle border as a placeholder frame via Sharp.
